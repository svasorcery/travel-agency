# Explore Domain

1. Remain read-only. Read the module `AGENTS.md` and inspect the actual Core, Application, Infrastructure, Api, and tests.
2. Return a current-state card: purpose and boundaries; implemented behavior by layer; public contracts and dependencies; test coverage; gaps and next decisions.
3. Cite paths or concrete repository evidence for every factual statement.

Separate verified facts, gaps, and uncertainty.
