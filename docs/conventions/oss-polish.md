# Convention: OSS Polish

## Что это

Полный набор стандартных OSS-файлов: лицензия, руководство по участию, политика
безопасности, кодекс поведения и GitHub-шаблоны (issue-формы, PR-шаблон, FUNDING).
Вместе они формируют «OSS hygiene» — базовое оформление публичного репо.

## Почему

GitHub Community Standards показывает прогресс-бар по наличию этих файлов.
Для showcase-репо полный набор обязателен: он сигнализирует посетителям, что проект
открыт для участия, имеет процесс и поддерживает стандартные каналы коммуникации.
Отсутствие хотя бы LICENSE или CONTRIBUTING снижает доверие и блокирует Contributors.

## Файлы

### `LICENSE`

MIT 2026, правообладатель — владелец организации.
Выбор MIT: минимальные ограничения, максимальная совместимость с зависимостями проекта.

### `README.md`

«Богатый» README: бейджи (CI, license, NuGet), quick start (`dotnet run`),
описание стека (Aspire / Wolverine / Marten / Angular / NX), роадмап подпроектов,
раздел «BYO keys» для API-ключей сторонних сервисов.

### `CONTRIBUTING.md`

- Требования к окружению (SDK-версии, Docker, Node)
- Как запустить проект локально
- Как запустить тесты
- Ожидаемый формат коммитов (Conventional Commits, `npm run commit`)
- Процесс код-ревью и мёрдж-политика

### `SECURITY.md`

- Адрес для сообщений об уязвимостях: `developer.pulsell@gmail.com`
- Таблица поддерживаемых версий (пока один тег `main`)
- SLA ответа: 72 часа

### `CODE_OF_CONDUCT.md`

Ссылка на Contributor Covenant 2.1 (каноничный URL):
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Полный текст не инлайним — он длинный и вызывает content-filter в некоторых средах.
Ссылки достаточно для GitHub Community Standards.

### `.github/PULL_REQUEST_TEMPLATE.md`

Чеклист при открытии PR:
- [ ] Тесты добавлены / обновлены
- [ ] Документация обновлена (если публичный API изменился)
- [ ] Сообщения коммитов соответствуют Conventional Commits
- [ ] `dotnet test` проходит локально

### `.github/ISSUE_TEMPLATE/`

| Файл | Тип |
|------|-----|
| `bug_report.yml` | Структурированная форма: шаги воспроизведения, ожидаемое / фактическое поведение, окружение |
| `feature_request.yml` | Мотивация, описание решения, альтернативы |
| `config.yml` | Отключает «blank» issue, добавляет ссылку на Discussions |

### `.github/FUNDING.yml`

Каналы спонсорства — пока плейсхолдер. Заполнить при необходимости.

## Что не делаем

Не инлайним полный текст Contributor Covenant: он занимает ~200 строк и может
срабатывать как content-filter. Ссылки на каноничный URL достаточно для всех
практических целей.
