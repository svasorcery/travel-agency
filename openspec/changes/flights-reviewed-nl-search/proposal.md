# Flights — заполнение формы поиска по фразе

## Why

Человек может знать, куда и с кем хочет полететь, ещё до выбора города вылета. Сегодня форма Flights принимает структурированные поля, а существующий API поиска по фразе при успешном разборе сразу ищет рейсы. Нужен способ проверить, что система поняла, дополнить маршрут и самому решить, когда искать.

## What Changes

- На странице Flights пользователь вводит фразу и нажимает «Заполнить форму». Распознанные значения появляются в обычных редактируемых полях. Для поиска в одну сторону или туда-обратно достаточно одной формы.
- Для «Хочу в Сочи на выходные, нас двое» форма показывает «Сочи (AER)», двух взрослых и предложенные даты субботы и воскресенья. У пустого поля вылета появляется вопрос «Из какого города вылетаете?». Ответить можно названием из локального списка или кодом, прямо в форме.
- Поля с недостающими или противоречивыми данными требуют уточнения. «Найти рейсы» запускает один структурированный поиск с текущими значениями, когда форма готова. Если AI недоступен, введённые вручную значения сохраняются и человек может завершить поиск сам.
- Добавляется отдельная операция разбора. Существующие клиенты `POST /api/flights/search/nl` по-прежнему получают результат поиска.
- Приёмка использует фиксированные вымышленные ответы AI и счётчики обращений к поиску и поставщикам. Бюджет внешних моделей — $0. Качество распознавания живой моделью потребует отдельной проверки.

## Impact

Новая операция затрагивает Flights API/Application/Composition, версионированные сообщения Host ↔ Travel.AI, отдельный промпт разбора, TypeScript API client и Angular-страницу Flights. Форма, валидация, структурированный API и отображение предложений уже существуют. Объём работ ограничен этапом от ввода фразы до запуска поиска.
