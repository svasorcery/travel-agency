## Alternatives and gaps

Прямой Support HTTP ACL минимален для одного consumer. Travel.AI proxy добавляет private-text hop и новый process contract; embedded Python/SDK/agent runtime требует lifecycle без retained benefit. Их не выбираем. Чистая keyword baseline сохраняется для S3 comparison, а S1 manual sorting остаётся рабочим control.

Не доказаны installed model/image, доверенный target, права/ключи/схема этого target, privacy approval для реального текста, runtime resource limits и RU/EN качество/пороги. Plan defaults off. Proposed24h urgency/512token window/guards/admission — reviewable policy, не ранее утверждённый operational SLA.
Independent review уточнил фактическую gate semantics по pinned [confidence.py](https://github.com/NandhaKishorM/laya/blob/c73908d96ff73c0062c340a11bf7c54ec7d8bc4d/laya/confidence.py): при полном choice ответе min_confidence относится к max-probability answer_confidence; entropy требует своей проверки. Passed gate удаляет low_confidence marker; отсутствие флага не означает отсутствие gate. Наличие abstention/threshold и required answer_confidence проверяются отдельно. Исправлено в D5, не объявлено принятой calibration.

Final review также проверил pinned serve.py health: scoped CPU fallback восстанавливает device, но увеличивает counter.
