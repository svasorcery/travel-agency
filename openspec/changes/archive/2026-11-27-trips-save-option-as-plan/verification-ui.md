# Сохранение варианта в интерфейсе Trips

27 ноября 2026 года полный набор Angular прошёл **1077/1077 в 71 файле**. В него входят **26/26** проверок карточки, совместимости и восстановления, которые также прошли отдельным запуском. Angular использовал настоящий компонент страницы и HTTP-клиент с вымышленными ответами через `HttpTestingController`.

| Задача | Наблюдение |
| --- | --- |
| 3.1 | Один клик отправляет один согласованный preview с текущим брифом и заголовком формата 1. Старый ответ показывает карточку без действия сохранения. Для расширенного ответа нативная кнопка получает клавиатурный фокус. Двойной клик отправляет один POST. Пользователь может уточнить название после просмотра. При пустом вводе клиент опускает поле. С ответом 201 маршрутизатор получает выданный ID. Обычное создание прошло регрессию. |
| 3.2 | После потери ответа клиент читает только выданный ID. Совпавшие бриф и снимок открывают поездку. Ответы 404, NULL, другой снимок, пустой список и отключённая запись сохраняют возможность восстановления. Повтор использует исходный талон. Обычное создание и новый подбор блокируются до явного выхода. Выход отменяет незавершённую проверку. Смена владельца, выход из сеанса и закрытие вкладки исключают навигацию по позднему ответу. Проверены URL, разметка, записи browser storage, отключение transfer cache и отсутствие отправки при SSR. |
| 3.3 | Чтение по версии сохранённого снимка показывает исходные дни с изменившимся хешем пакета и другими датами редактора. Обе части поездки помечены «Запланировано». Подытог исходной карточки остаётся отдельно от ручных оценок. На RT3/H3 и бюджете 1 EUR цена поставщика подписана отдельно, расходы в RUB сохранены без конвертации. Неизвестная версия вызывает видимую ошибку, явный NULL убирает слой. В полном наборе прошли существующие операции рабочего календаря, жилья и ссылок на заказы. |

В шестёрке проверок `SavedOptionProtectionTests` сервер сохранил и прочитал эталоны A/B, короткую поездку и бюджет в евро. Негативные примеры отвергнуты при выдаче и чтении исторической записи. Валидные Unicode-поля заполнили preview до ровно 32 КиБ и сохраняемую запись до ровно 40 КиБ. Добавление одного байта дало отказ. Клиент проверил границы 32 КиБ для прежнего ответа, 64 КиБ для талона и 128 КиБ для расширенного ответа. Чужая ссылка и несогласованный подытог были отклонены.

## Воспроизведение

Команды выполнялись из корня репозитория. Для Angular использован локальный Node 24.22.3. На установленном Node 26.11.1 Vitest завершался с таймаутом запуска процесса до выполнения тестов. Временный конфиг для Vitest содержал только выбор пула потоков и его размера.

```powershell
$env:NX_DAEMON = 'false'
$env:NX_ISOLATE_PLUGINS = 'false'
$env:CI = 'true'
$runnerConfig = Join-Path ([IO.Path]::GetTempPath()) ("trips-vitest-{0}.mjs" -f [guid]::NewGuid())
Set-Content -LiteralPath $runnerConfig -Value "export default { test: { pool: 'threads', maxWorkers: 2 } };"
try {
    node node_modules/nx/dist/bin/nx.js test web --watch=false --skip-nx-cache --include=apps/web/src/app/trips/trips-option-preview.component.spec.ts "--runnerConfig=$runnerConfig"
    if ($LASTEXITCODE) { throw 'Focused Angular tests failed' }
    node node_modules/nx/dist/bin/nx.js test web --watch=false --skip-nx-cache "--runnerConfig=$runnerConfig"
    if ($LASTEXITCODE) { throw 'Angular suite failed' }
} finally {
    Remove-Item -LiteralPath $runnerConfig
}
node node_modules/typescript/bin/tsc --noEmit -p apps/web/tsconfig.spec.json
node node_modules/@angular/compiler-cli/bundles/src/bin/ngc.js --noEmit -p apps/web/tsconfig.app.json
dotnet test tests/trips/Travel.Modules.Trips.Tests.Integration/Travel.Modules.Trips.Tests.Integration.csproj --no-restore -m:1 --disable-build-servers --filter FullyQualifiedName~SavedOptionProtectionTests
```

## Демо с перехватом HTTP

Старая вымышленная сетевая фикстура отклонила новый GET исторического слоя при открытии ручного плана. Падение воспроизведено в Chromium на сценарии ночного перелёта. Для существующей поездки владельца фикстура теперь отвечает `{"savedOption":null}`. После исправления все **99/99** сценариев прошли за 5,2 минуты с одним worker и без повторов, включая обычное создание, ручной календарь, Flights, Hotels, Rail, прогулки и разбор брифа. Проверки чужого ID, метода, параметров запроса и журнал неизвестных обращений продолжают действовать.

Для повторного прогона на `127.0.0.1:4203` используется стандартная конфигурация демо с отдельным каталогом результатов.

```powershell
$run = "trips-saved-option-demo-{0}" -f [guid]::NewGuid()
$env:TRIPS_DEMO_ARTIFACTS_DIR = Join-Path (Resolve-Path TestResults) $run
node node_modules/@playwright/test/cli.js test --config=tests/travel-e2e/playwright.trips-demo.config.ts "--output=TestResults/$run-playwright" --reporter=line
```
