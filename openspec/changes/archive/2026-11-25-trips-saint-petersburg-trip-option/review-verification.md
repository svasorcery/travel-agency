## Обычное демо

Стандартная генерация Compose для обычного режима побайтно эквивалентна по содержанию конфигурации базового коммита. С явно выбранным флагом изменяются только запросы IPAM для двух сетей. [Сравнение конфигураций](receipts/review-ordinary-config.json)

Первый одновременный холодный старт с /24 не уложился в штатный бюджет. На этом экземпляре последующий обычный `up` без флага успешно использовал существующие ресурсы, а повторное указание `--small-subnets` было отклонено. После перезапуска Host, Keycloak и PostgreSQL следующий вход открыл тот же сохранённый план, без записи. [Повторное чтение](receipts/review-ordinary-reopen.json)

Положительная приёмка свежего запуска выполнена отдельно на `20367eda18778bfba2aca32d7e53fac1`. Шесть сервисов стали доступны, OIDC ответил примерно через 105 секунд от старта контейнера Keycloak, `up --small-subnets` завершился с кодом 0 при бюджете 180 секунд. Реальный браузер прошёл PKCE, создание плана (201) и чтение (200); владелец и анонимный пользователь получили 404 на обоих маршрутах исторического профиля. Ход времени совпал с системным; обычные прогулки с истёкшим релизом Петербурга вернули 503. [Свежий запуск](receipts/review-ordinary-up.json) · [Браузер](receipts/review-ordinary-browser.json) · [Перезапуск и уборка этого же стенда](receipts/review-ordinary-final-lifecycle.json)

Прежний петербургский профиль `9e887d7227415c9ea4d4ce62e0d9dd5b` завершил все 14 этапов, включая перезапуск трёх сервисов, повторный вход и чтение защищённого плана. Три входа, один исходный запрос маршрута, ноль внешних запросов, `storagePreserved=true`, уборка прошла. [Квитанция прежнего профиля](receipts/review-previous-petersburg.json)

Финальная инвентаризация по восьми ID подтвердила отсутствие контейнеров, сетей и томов этих запусков. Порты 4205/8185/4206/8186 одновременно заняты проверочными слушателями и освобождены. Временная копия удалена; исходное сохранённое демо и проверенные посторонние ресурсы сохранили свои отпечатки. [Протокол уборки](receipts/review-resources.json)

## Границы проверок

Проверка ошибки до достижения браузерной стадии из-за одновременной сборки не учитывалась при закрытии 1.2. Принятый аварийный прогон достиг запущенных Host, Keycloak, PostgreSQL, Redis, NATS и ingress. Обычный `up` по умолчанию в независимой копии получил отказ Docker из-за исчерпания стандартных подсетей. Эта попытка не считается доказательством работы обычного демо. Историческое состояние основного checkout имеет прежнее расхождение Compose с базовой версией и сохранено отдельно.

В основном рабочем каталоге дополнительный валидатор инвентаря .NET обнаружил 60 старых игнорируемых проектов под `TestResults`. На изолированной исходной копии тот же валидатор вернул ноль расхождений. Эти файлы не удалялись.
