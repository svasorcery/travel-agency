## Предварительные решения по интеграции

- CI: новые Unit и terminal adapter/lean HTTP tests добавляются явными обязательными командами в существующий `test-host-http` job; отдельные manifest lanes для каждого test project, без новой topology/timeout/skip/continue-on-error. Trips остаётся scaffold. Это исходный CI contract, не выполненная CI приёмка.
- Outbound `IHttpUrlRedactionContributor` не закрывает inbound q: нужны отдельные реально emitted log/span/error проверки для incoming autocomplete, без ослабления остальных module/platform policies.
- Known pending gates4.3(actual Host/OpenAPI), ordinary CI receipt,7.1(measured load), supplier/access/rights/quota/official banner и target rollout не закрываются lean/source proof.
- Дополнительная проверка полноты: GetUtcNow-only test clock не управляет timers. Deadline/cooldown/profile/cancel/bundle-clipping и совокупный output limit требуют исполняемых controlled-time/boundary tests до source приёмки; browser launch failure не является behavioral RED.
- Ruling — CSP: исходный web server/index не содержит CSP, Keycloak использует настраиваемый origin. Для выполнения уже согласованного CSP/auth-preservation принят один document-level frame policy owner до app/auth bootstrap: self, точный официальный banner endpoint, только валидированный существующий auth origin. Не менять auth flow, не добавлять wildcard, не удалять/ослаблять другие политики. Проверить direct Rail и SPA Flights→Rail; target header может дополнительно ограничивать meta и остаётся отдельным deployment gate. Отложенный баннер не считается выполнением UI task5.2.
